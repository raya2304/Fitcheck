# FitCheck – BMI Calculator

FitCheck is a responsive BMI Calculator website that allows users to calculate their Body Mass Index using their age, height, and weight. The website provides instant BMI results along with the corresponding BMI category and useful wellness information.

## Features

* Calculate BMI using height and weight
* Display BMI value instantly
* Show BMI categories
* Input validation and error messages
* Reset calculator functionality
* BMI range guide
* Quick BMI facts
* Healthy lifestyle tips
* Responsive design for desktop, tablet, and mobile
* Smooth navigation between sections
* Clean and modern wellness-focused interface

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript

## How It Works

The BMI is calculated using the formula:

**BMI = Weight (kg) / Height² (m)**

Users enter their height and weight, and JavaScript calculates the BMI value and identifies the corresponding category.

## BMI Categories

| BMI Range    | Category       |
| ------------ | -------------- |
| Below 18.5   | Underweight    |
| 18.5 – 24.9  | Healthy Weight |
| 25 – 29.9    | Overweight     |
| 30 or higher | Obesity        |

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter your details.
5. Click **Calculate BMI** to view the result.

## Purpose

This project was created as a frontend development practice project to demonstrate responsive web design, Tailwind CSS styling, JavaScript calculations, form validation, and interactive UI functionality.

## Disclaimer

BMI is a general screening measure and does not directly measure body fat, muscle mass, or overall health. The results should not be considered a medical diagnosis.
